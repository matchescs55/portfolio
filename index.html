CONFIGURACIÓN Y DESPLIEGUE EN NETLIFY

Cómo publicar esta web completa en Netlify para que incluya todos los 13 juegos

PASOS PARA PUBLICAR EL PORTAFOLIO:

  1. Guarda este archivo HTML en la carpeta raíz como index.html.
  2. Crea un repositorio en GitHub con este código.
  3. Inicia sesión en Netlify.com, crea un sitio desde GitHub.
  4. Configura el directorio de publicación como raíz (.) o carpeta public.
  5. ¡Listo! Tu portafolio retro con los 13 juegos quedará en línea al instante.
